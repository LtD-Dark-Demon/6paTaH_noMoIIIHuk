# Братан — голосовой ассистент для Android

Гибридный офлайн/онлайн голосовой ассистент для Android 11–14. Слушает речь
в фоне, реагирует на стартовое слово, понимает команды локально (правила +
опциональная TFLite-модель) и через Claude API, выполняет действия.
Протестирован на Xiaomi Redmi Note 14 4G (HyperOS 1.0.3.0, Android 14,
MediaTek Helio G99-Ultra, 6 ГБ ОЗУ).

## Как это работает

Три уровня обработки (каждый следующий — только если предыдущий не уверен):

1. **Кэш** (`CommandCache`) — LRU 100 записей + TTL 10 мин, нечёткое
   совпадение (Jaccard ≥ 0.8 по основам слов). Для фраз с цифрами нечёткий
   поиск отключён.
2. **Локально** (`ChainLocalModel`):
   - `RuleBasedIntentProvider` — regex-правила, мгновенно, уверенность 0.92;
   - `TFLiteModelProcessor` — квантованный BERT (TFLite), если файлы положены
     в assets. Загружается лениво, при нехватке памяти или простое 5 минут —
     выгружается. Только XNNPACK (CPU): NNAPI на MediaTek нестабилен.
3. **Облако** (`ClaudeApiProvider`) — только если задан API-ключ И локальный
   результат не уверен. Таймаут 2 с. Circuit Breaker: 3 сбоя подряд →
   облако отключено на 10 минут (с полуоткрытым состоянием для повтора).

Слияние — `ConfidenceMergeStrategy`: максимум уверенности из всех источников.

Действия — строго по белому списку. Фонарик — через `TorchController`
(учитывает занятость камеры `CAMERA_IN_USE`). Wi-Fi и календарь —
уведомление-кнопка: Android 10+ запрещает открывать Activity из фона.

## Сборка

### Вариант 1: GitHub Actions
1. Залейте проект в ветку `main`.
2. Workflow запускает unit-тесты, Android Lint и release-сборку автоматически
   (или Actions → Build APK → Run workflow).
3. Скачайте артефакт **bratan-apk**. Полный проект с Gradle Wrapper — артефакт
   **bratan-project**.

### Вариант 2: локально (JDK 17 + Android SDK 34)

Gradle Wrapper в проекте: **8.10.2**. APK подписан debug-ключом: для личного
использования, в Google Play не загрузить.

```bash
./gradlew :app:testReleaseUnitTest :app:lintRelease :app:assembleRelease
```

## Установка

1. Установите APK (разрешите установку из неизвестных источников).
2. Откройте, введите ключ Anthropic API (необязательно) и стартовое слово
   (по умолчанию «братан»; пусто = вся речь).
3. **Старт** → выдайте микрофон и уведомления.

## Xiaomi / Redmi / POCO (HyperOS) — обязательно

Системная «Оптимизация батареи» на HyperOS **не защищает** сервис: демоны
PowerKeeper/Joyose убивают процесс независимо от неё. Выполните все пункты
карточки на главном экране (появляется только на Xiaomi):

1. **Автозапуск** → включить (кнопка открывает нужный экран).
2. **Контроль активности** → «Нет ограничений» (кнопка открывает нужный экран).
3. Недавние приложения → зажать карточку «Братан» → **замок**.
4. Настройки → Расширенные → **Расширение памяти → Выкл.** Swap на UFS 2.2
   вызывает фризы аудиопотока и срабатывание OOM-киллера.
5. Отключить «О'кей, Google» / Voice Match — конкурент за микрофон.
6. Остальные устройства: **«Настройки батареи»** → «Не ограничивать».

Если HyperOS всё же убил сервис, при перезапуске появится уведомление
«Братан перезапущен системой — нажмите». На Android 14 для восстановления
доступа к микрофону может потребоваться один тап по уведомлению. То же после
перезагрузки телефона.

Приложение не использует SCHEDULE_EXACT_ALARM, Full-Screen Intent,
SYSTEM_ALERT_WINDOW, NNAPI и дочерние процессы. Зелёная точка микрофона в
статус-баре — требование системы, скрыть нельзя.

## Использование

Примеры:
- «братан, включи фонарик» / «выключи фонарик» — сразу;
- «братан, включи вай-фай» — уведомление-кнопка → панель Wi-Fi;
- «братан, напомни завтра в 18:30 позвонить маме» — уведомление →
  создание события; при наличии API-ключа дату/время извлекает облако.

Журнал последних 20 команд — на экране приложения. Остановка: «Стоп» в
приложении или в уведомлении. Смена настроек: «Старт» ещё раз — сервис
перезапустится с новыми значениями.

## Локальная TFLite-модель (опционально)

Положите в `app/src/main/assets/` **до сборки**:

| Файл | Что это |
|---|---|
| `mobilebert_quant.tflite` | квантованный классификатор интентов |
| `vocab.txt` | словарь WordPiece, совпадающий с моделью |
| `intents.txt` | карта выходов (образец: `intents.txt.example`) |

Требования: модель с русским словарём (например, на базе rubert-tiny2;
английский MobileBERT русский текст превратит в [UNK]), квантование
Dynamic Range (вход/выход float32; полное int8 не поддерживается), имена
входов содержат mask / type или segment для масок и сегментов.

Формат `intents.txt`: порядок строк = порядок выходов модели,
`ИНТЕНТ|действие1,действие2`. Не убирайте `noCompress "tflite"` из
`app/build.gradle.kts` — без него mmap модели падает.

## Устранение неполадок

| Симптом | Решение |
|---|---|
| «Распознавание речи недоступно» | Установите/включите приложение Google |
| «Нет разрешения на микрофон» | Выдайте разрешение, нажмите «Старт» |
| Сервис умирает в фоне | Выполните все пункты раздела HyperOS |
| «Перезапущен системой — нажмите» | Тап по уведомлению восстанавливает микрофон |
| Облако молчит | Проверьте ключ; Circuit Breaker после 3 сбоев ждёт 10 мин |
| Напоминание без времени | Нужен API-ключ — время парсит облако |
| Распознавание требует сеть | Настройки Google → Голосовой ввод → Офлайн-распознавание → Русский |
| Фонарик «занят камерой» | Открыта камера или идёт разблокировка по лицу — повторите позже |
| TFLite «пропущен: мало памяти» | Свободно < 512 МБ; отключите Расширение памяти |
| TFLite «выгружен (простой)» | Нормально: грузится по требованию при следующей команде |
| Команда не слышится во время звонка | Так задумано: микрофон занят связью |
| «Распознаватель завис» | Watchdog перезапускает через 60 с; при включении экрана — сразу |
| Сборка падает на Sync | JDK 17; в Studio: Settings → Build Tools → Gradle → Gradle JDK |

## Архитектура

| Файл | Роль |
|---|---|
| Models.kt | интерфейсы, CommandResult, белый список |
| SmartAssistantInteractor.kt | кэш → локально → облако → слияние |
| CommandCache.kt | LRU + TTL + нечёткий поиск |
| RuleBasedIntentProvider.kt | правила |
| TFLiteModelProcessor.kt | TFLite (mmap, Mutex, XNNPACK, ленивая загрузка) |
| BertTokenizer.kt | WordPiece |
| ClaudeApiProvider.kt | HTTP к Anthropic |
| CircuitBreakerProvider.kt | защита облака |
| AndroidActionExecutor.kt | действия, белый список |
| TorchController.kt | фонарик с учётом занятости камеры |
| ModularVoiceService.kt | FGS, SpeechRecognizer, watchdog, деградация режимов |
| RecoveryNotifier.kt | уведомление восстановления после убийства/перезагрузки |
| BootReceiver.kt | после перезагрузки — уведомление вместо старта |
| XiaomiCompat.kt | экраны Автозапуск и Контроль активности |
| MainActivity.kt, Prefs.kt | UI и настройки |
| ServiceBus.kt | журнал сервис → UI |

Расширение: новый облачный провайдер — реализуйте `IntentProvider` и добавьте
в `ModularVoiceService.onCreate()`. Новое действие — ветка в
`AndroidActionExecutor.execute()` + имя в `SYSTEM_PROMPT`.

## Безопасность и приватность

- Без API-ключа текст команд не покидает устройство.
- Ключ хранится в приватных SharedPreferences; `allowBackup=false`.
- Белый список действий: произвольный вывод нейросети ничего не исполнит.
- Cleartext-трафик запрещён; сервис не экспортирован.
