# Братан — голосовой помощник для Android

Фоновый голосовой ассистент: слушает речь, реагирует на стартовое слово («Братан»), понимает команды локально (правила + опциональная TFLite-модель) и через Claude API, выполняет действия.

Требования к телефону: Android 11+ (minSdk 30), arm64 (Helio G99 и любые современные Redmi/Xiaomi), на устройстве есть приложение Google (служба распознавания речи).

## Часть 1. Получение APK (выберите один способ)

### Способ A. GitHub Actions (без установки чего-либо на ПК)

1. Создайте на github.com **приватный** репозиторий `BratanAssistant` (без README и .gitignore).
2. Распакуйте архив проекта. В папке проекта откройте PowerShell (Windows):
   ```powershell
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/BratanAssistant.git
   git push -u origin main
   ```
3. Откройте репозиторий → вкладка **Actions** → workflow **Build APK** (запускается сам после push; при необходимости **Run workflow**).
4. Дождитесь зелёной галочки (3–6 минут) → откройте запуск → внизу **Artifacts** → скачайте `bratan-apk` (zip) → внутри `app-release.apk`.

### Способ B. Android Studio (Windows)

1. Установите Android Studio (https://developer.android.com/studio), при первом запуске согласитесь на установку Android SDK.
2. **File → Open** → выберите папку проекта. Дождитесь окончания Gradle Sync (первый раз 5–10 минут, нужен интернет).
3. Если Studio просит SDK Platform 34 — нажмите на ссылку установки в сообщении.
4. Откройте вкладку **Terminal** внизу и выполните:
   ```powershell
   .\gradlew.bat :app:assembleRelease
   ```
5. APK: `app\build\outputs\apk\release\app-release.apk`.

### Способ C. Только командная строка

Нужны JDK 17 и Android SDK (платформа 34, build-tools 34). В `local.properties` в корне проекта укажите путь к SDK:
```
sdk.dir=C\:\\Users\\ИМЯ\\AppData\\Local\\Android\\Sdk
```
Затем `.\gradlew.bat :app:assembleRelease`.

## Часть 2. Установка на телефон

1. Скопируйте `app-release.apk` на телефон (Telegram «Избранное», USB, облако).
2. Откройте файл. Разрешите установку из этого источника, когда спросит система.
3. Если Play Protect предупреждает о неизвестном приложении — **Всё равно установить** (APK подписан локальным ключом, это ваш личный билд).

## Часть 3. Первая настройка

1. Откройте приложение «Братан».
2. **Ключ Anthropic API** (необязательно). Без ключа работают только локальные правила, и ничего не уходит в сеть. Ключ получают в консоли Anthropic; хранится только в приватных настройках приложения.
3. **Стартовое слово** — по умолчанию «братан». Обрабатываются только фразы, начинающиеся с него. Пустое поле = слушать и обрабатывать всё (с ключом это значит отправлять всю услышанную речь в облако; не рекомендуется).
4. Нажмите **Старт** → разрешите микрофон и уведомления.
5. Нажмите **Настройки батареи** → найдите «Братан» → выберите «Не ограничивать / Без ограничений».
6. Только для Xiaomi/HyperOS: Настройки → Приложения → Разрешения → **Автозапуск** → включить для «Братан»; в списке недавних приложений зажмите карточку «Братан» → **Заблокировать** (иначе система убивает сервис).
7. Офлайн-распознавание русского (чтобы не зависеть от интернета): Настройки Android → Google → Голосовой ввод / Службы Google → Офлайн-распознавание речи → Русский → скачать. Без пакета приложение само переключится на онлайн-распознавание.

## Часть 4. Использование

Говорите: **«Братан, …»**

| Фраза | Результат |
|---|---|
| «Братан, включи фонарик» / «выключи фонарик» | Сразу включает/выключает вспышку |
| «Братан, включи вайфай» / «выключи вайфай» | Уведомление «Нажмите, чтобы переключить Wi-Fi» → панель Wi-Fi |
| «Братан, напомни купить хлеб» | Уведомление → форма события в Календаре с заголовком |
| Любая другая фраза (при наличии ключа) | Claude определяет действие из белого списка (то же самое + календарь с датой) |

Результаты видны на экране приложения (последние 20 команд). Остановить: кнопка **Стоп** или «Стоп» в уведомлении.

Почему Wi-Fi и календарь — через уведомление: начиная с Android 10 система запрещает приложению переключать Wi-Fi и открывать окна из фона. Обойти это без root/системных прав нельзя.

## Часть 5. Локальная нейросеть (необязательно)

Приложение работает без неё. Чтобы подключить:

1. Нужна **дообученная классификация интентов** TFLite-модель (вход: `input_ids` [+ `attention_mask`, `token_type_ids`], int32 или float32; выход: вектор вероятностей/логитов по интентам). Имена входов должны содержать `mask` / `type` или `segment` для масок и сегментов, иначе вход считается `input_ids`.
2. Для русского языка нужна модель с русским словарём (например, на базе rubert-tiny2). Оригинальный MobileBERT англоязычный и русские фразы почти целиком превратит в `[UNK]`.
3. Положите в `app/src/main/assets/`:
   - `mobilebert_quant.tflite` (или другое имя — тогда поправьте в `TFLiteModelProcessor`),
   - `vocab.txt` — словарь BERT WordPiece от этой же модели (lowercase),
   - `intents.txt` — по образцу `intents.txt.example` (порядок строк = порядок выходов модели).
4. Пересоберите APK. Если файлов нет, TFLite отключается тихо (в логе `Локальная модель недоступна`).

Модель должна быть квантована Dynamic Range (вход/выход float32). Полное int8-квантование входов/выходов не поддерживается.

## Часть 6. Архитектура

```
Models.kt                    интерфейсы и CommandResult
ConfidenceMergeStrategy.kt   выбор лучшего результата
SmartAssistantInteractor.kt  кэш → локально → (если не уверен) облако → слияние
CommandCache.kt              LRU + TTL + нечёткое совпадение
RuleBasedIntentProvider.kt   правила + ChainLocalModel
TFLiteModelProcessor.kt      TFLite (mmap, Mutex, XNNPACK, 2 потока)
BertTokenizer.kt             WordPiece
ClaudeApiProvider.kt         HTTP к Anthropic + CircuitBreakerProvider
AndroidActionExecutor.kt     действия (белый список)
ModularVoiceService.kt       foreground-сервис с микрофоном
MainActivity.kt, Prefs.kt    экран и настройки
```
Новый облачный провайдер: реализуйте `CloudApiProvider` и добавьте в список в `ModularVoiceService.onCreate()`.
Новое действие: добавьте ветку в `AndroidActionExecutor.execute()` и имя действия в `SYSTEM_PROMPT` (`ClaudeApiProvider`).
Модель Claude меняется параметром `model` в `ClaudeApiProvider` (по умолчанию `claude-haiku-5-5`).

## Часть 7. Что сохранено и что изменено относительно кода Gemma

**Сохранено без изменений:** memory-mapping модели, Mutex вокруг TFLite, XNNPACK, 2 потока, `Dispatchers.Default` для инференса и `Dispatchers.IO` для сети, таймаут облака 2 с, ранний выход при уверенности ≥ 0.85, кэш результатов > 0.8, SupervisorJob, `EXTRA_PREFER_OFFLINE`, задержка 500 мс перед перезапуском, `START_STICKY`, `foregroundServiceType="microphone"`, отмена корутин в `onDestroy`.

**Исправлено (`[FIX]` в коде):**
- Локальная модель всегда возвращала «TURN_ON_WIFI» 0.92 вне зависимости от фразы; облако — всегда «COMPLEX_SCHEDULE» 0.98 без запроса. Теперь реальные правила и реальный HTTP-запрос.
- Облако запускалось всегда, даже при уверенном локальном ответе. Теперь только если локальный не уверен.
- Блокирующий HTTP не отменялся `withTimeoutOrNull` — добавлены таймауты сокета.
- `catch (e: Exception)` глотал `CancellationException`.
- `releaseResources()` мог закрыть интерпретатор во время инференса; `AssetFileDescriptor` не закрывался.
- Нет `noCompress "tflite"` → `openFd` падал; нет `kotlinx-coroutines-android` → падение на `Dispatchers.Main`.
- `startForeground` без типа сервиса на Android 14; повторный `startListening` при повторном `onStartCommand`; бесконечный перезапуск при ошибке разрешений; не было `<queries>` для SpeechRecognizer.
- Любая услышанная речь уходила в обработку/облако → теперь стартовое слово.
- Ключ API был вшит в код → ввод в приложении.
- Не было `ActionExecutor` → реализован.
- Кэш рос бесконечно → LRU + TTL.
- Слияние всегда отдавало облако → теперь максимум уверенности из всех.

**Добавлено (`[OPT]`):** Circuit Breaker (3 сбоя → 10 мин паузы), пересоздание интерпретатора на 1 поток при нагреве (ThermalStatus), переиспользуемые буферы инференса, нечёткий кэш, debounce повторных фраз, экспоненциальная пауза при ошибках распознавания, WakeLock с таймаутом 10 с, фильтр ABI `arm64-v8a`.

**Не реализовано из анализа Gemma:** «пульсирующий» VAD (SpeechRecognizer уже содержит собственный VAD), перезапуск через WorkManager, реальный семантический кэш на эмбеддингах (сделан лексический), очередь офлайн-команд в Room.

## Часть 8. Частые проблемы

| Симптом | Решение |
|---|---|
| Сервис останавливается сам | Шаги 5–6 части 3; перезапустите кнопкой «Старт» при открытом приложении |
| «Распознавание речи недоступно» | Установите/включите приложение Google и службу распознавания речи |
| Постоянный звук «дзынь» | Так работает системный SpeechRecognizer при каждом перезапуске; снизить можно только отключив звук уведомлений/медиа в этот момент |
| Облако не отвечает | Проверьте ключ; после 3 сбоев подряд облако отключается на 10 минут (перезапуск сервиса сбрасывает) |
| Постоянная точка микрофона | Требование Android 12+, отключить нельзя |
| Сборка падает на Sync | JDK 17 (в Studio: Settings → Build Tools → Gradle → Gradle JDK) и доступ к google()/mavenCentral() |
